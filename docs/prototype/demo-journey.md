# Hackathon demo journey

## Status and scenario

This is a proposed demonstration script. **Kofi is a fictional collector.** All accounts, locations, prices, images, records, evidence, model outputs, and programme results used in the demo must be controlled and labelled demonstration data. No listed business is automatically an approved recycler. Payment/EPR/government capabilities are not part of this journey.

Target presentation time: approximately 8–10 minutes, subject to organiser rules and rehearsal. Durations below are estimates, not service-performance targets.

## Pre-demo declaration

The presenter states: “This is a controlled ScrapTrace demonstration. Prices are indicative samples, locations and identities are fictional or authorised demonstration entries, recycling evidence is simulated, and no real payment, recycler certification, government approval, or EPR credit is being issued.”

## Script

|---|---|---|---|---|---|
| 1. ## Optional review branch

If time permits, demonstrate one clearly fictional flagged record: a low-confidence prediction, category mismatch, repeated-image signal, unusual-weight signal, or missing evidence. Show that the programme reviewer sees a reason, requests information or decides with rationale, and that the flag is not automatically proof of fraud.

## External-service backup behaviour

| Failure | Rehearsed backup | Required explanation |
|---|---|---|
| Vision unavailable/slow | Use a prerecorded response tied to the exact demo image/version or manually select category; label replay/manual mode | No live inference claim; manual selection remains valid for the controlled journey |
| LLM unavailable/invalid | Display the approved source card or previously validated cached demo response with version/freshness; label cached | The application never asks the LLM to guess and does not claim fresh generation |
| Map/directions unavailable | Use cached list/manual area and controlled location profile; label live directions unavailable | Directory participation/status is owned by ScrapTrace programme data, not the map provider |
| Network unavailable | Continue rehearsed offline capture/queue; use prerecorded server sync/journey if connectivity does not return | Local work is not server received or verified until acknowledged |
| Object upload fails | Keep evidence pending and use a prepared record for later steps; label the switch | Failed evidence never becomes complete |
| Dashboard/API unavailable | Use a timestamped prerecorded walkthrough/screenshots of the same controlled record/version | A recording is backup evidence, not a live system claim |

## Demo preparation controls

- Rehearse primary and every backup path on the presentation device/network.
- Pin/record the demo source revision, contracts, model, content, prompt/policy, data manifest, and environment.
- Use airplane/network controls only when they do not risk losing the presentation session.
- Preload approved cached assets and verify no real personal data, credentials, browser autofill, unrelated tabs, notifications, or provider dashboards are exposed.
- Reset the controlled dataset between rehearsals and ensure repeated submissions do not corrupt the final run.
- Keep a local video/slides backup accessible without cloud login.
