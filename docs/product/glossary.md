# Product glossary

| Term | Meaning |
|---|---|
| Approved and completed | Terminal programme state reached after required evidence passes checks or an authorised reviewer approves it. |
| Batch | Declared group of small parts or mixed scrap tracked under one recovery record. |
| Collector | Person who finds, collects or brings e-waste into the journey; a household user uses the same baseline application role. |
| Confidence | Model score describing how strongly an image matches a category; never certainty. |
| EPR | Extended Producer Responsibility, a policy approach in which producers have responsibility for products after use. |
| Evidence | Protected image, measurement, form entry or event supporting a recovery step. |
| Flag | Named indicator requiring human attention; not proof of fraud. |
| Grounding | Restricting an LLM response to supplied approved facts. |
| Handoff | Event in which a receiving location accepts and weighs an item or batch. |
| Idempotency key | Unique value that makes repeated network requests produce one logical result. |
| Indicative price | Non-binding range based on reference information before inspection and weighing. |
| LLM | Large Language Model used only to explain, simplify or translate approved safety content. |
| Mixed scrap | Batch of assorted electronic parts or materials requiring user-entered approximate weight for estimation. |
| Offline-first | Design that saves useful work locally and synchronizes when connectivity returns. |
| Programme | Authorised collection, take-back or incentive initiative using records under defined rules. |
| PWA | Progressive Web Application with installation-like behaviour and offline caching. |
| Recovery record | Aggregate linking collection, guidance, estimate, destination, handoff, processing and review. |
| Recycler | Participating receiving or processing organisation; verification status is displayed separately. |
| Safety card | Versioned, human-approved facts for one category and language. |
| Simulated incentive | Demonstration-only calculation that moves no funds. |
| Verified location | Profile reviewed by an authorised programme manager; the badge is not universal legal certification. |

The [approved SRS](<ScrapTrace_Software_Requirements_Specification (2).docx>) controls these definitions.
